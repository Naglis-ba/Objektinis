# Objektinis

Programa:
Programa skirta skaičiuoti mokinių pažymių vidurkius ir gauti rezultatus pasirinktu formatu.
Programoje yra galimybė įvesti mokinį ir jo rezultatus, sugeneruoti mokinio balus, taip pat 
skaityti mokinių sąrašą iš failo.

Tikslas:
0.3 versija skirta palyginti C++ kalbos duomenų struktų list ir vector spartą apdorojant didelius kiekius duomenų.

Sistemos specifikacijos:
Procesorius: AMD Ryzen 7 7435HS, 3100 Mhz, 8 branduoliai, 16 loginių procesorių
RAM: 16GB
Diskas: SSD
